====IDEIA====
input -> exe -r 20 -d 100 -o /path/to/csv -t GET https://url.com

-r == request amount (defaults to 100)
-d == delay between every request call (defaults to 1000ms) 
-o == outpath of benchmark csv (defaults to terminal)
-t == method used on the url (defaults to GET)
https://url.com == url called
